# speedМЭШ

Расширение для браузеров на базе Chromium, которое добавляет инструменты для работы с электронным дневником и кабинетом преподавателя МЭШ.

Расширение работает на `school.mos.ru` и `dnevnik.mos.ru`. Настройки функций доступны в popup расширения.

## Возможности

### Ассистенты урока

- **Таймер звонков** — показывает таймер урока и перемены.
- **Дни рождения** — отмечает дни рождения учеников. (в процессе разработки)
- **Кого спросить?** — помогает выбрать обучающегося для опроса из списка. 
- **Без домашнего задания** — позволяет отметить выбранные пары уроков в расписании для автоматического назначения "Без домашнего задания".

### Автоматизация журнала

- **Умные оценки** — инструменты для автоматического выставления оценок в журнале.
- **Цвета баллов** — визуально выделяет средние баллы в журнале группы.
- **Радар пропусков** — показывает информацию о пропусках, болезнях, сумме баллов обучающегося.
- **Ассистент КТП** — выполняет достроение и пересчёт КТП, показывает результаты и позволяет скачать лог.

### Системные утилиты

- **Турбо-интерфейс** — отключает анимации и переходы на страницах МЭШ.
- **Архитектор** — позволяет скрывать элементы страницы и менять их цвет.
- **Зал славы** — показывает достижения полученные в процессе работы с расширением.

## Без домашнего задания

1. В настройках расширения включите переключатель **Без домашнего задания**.
2. Откройте страницу расписания МЭШ и нажмите на карточку нужной пары уроков. Выбранная пара подсветится.
3. Выберите остальные пары и нажмите **Применить**.
4. Подтвердите действие. Расширение откроет урок, выберет его дату в календаре и нажмёт **Сохранить**.

Расширение обрабатывает только даты, доступные для выбора в календаре. Если дата недоступна или МЭШ не подтверждает сохранение, результат будет показан в панели. После завершения обработки расписание обновится.

Переключатель функции находится в окне расширения. При отключении панель выбора скрывается, а подсветка снимается.

2. Откройте `chrome://extensions/` в Chrome, Edge, Яндекс Браузере или другом Chromium-браузере.
